## Notable findings
1. SAFETY IS PERFECT: Strands Decider 2B correctly classified every emergency/safety case
   (safety_concern) at 100% accuracy with high confidence (0.85–0.93). This is the most
   critical question for Maruthuva Mozhi — zero misses on life-threatening situations.

2. AMBIGUITY DETECTION WEAKER: needs_clarification accuracy is 88.9% — the decider
   occasionally misclassifies OCR-garbled text (e.g. "Am0xici11in 5O0mg") or conflicting
   discharge notes. Two cases fell below the 0.70 confidence threshold (sent_to_human).
   These are good candidates for question-wording improvement in a second tuning pass.

3. LLM BASELINE POOR ON is_clear (47.1%): The LLM (qwen3.5-4b at ugmdu) systematically
   over-classifies documents as clear, even when ambiguous. This makes the decider clearly
   superior for this use case — it is both faster and more accurate.

4. RATE LIMITING: The ugmdu API enforces 1 concurrent request. Bench runs must be sequential
   and may need retries. The tune split ran successfully; the test split was affected by
   residual concurrency from prior sessions. Re-run test split in a fresh session when
   rate limits are clear.

5. LATENCY AT HOSTED API: ~3.1 s per decision at ugmdu (includes network round-trip).
   A GPU-local decider would be ~0.1–0.3 s. For the demo this is acceptable; for production,
   a co-located decider is recommended.
